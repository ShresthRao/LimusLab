# LimusLab
An open source slimey rogelike that involves 4 floors and monsters that need to be defeated to power up.

<img width="320" height="320" alt="image" src="https://github.com/user-attachments/assets/f9f6caf9-77e6-45f8-b840-361ef1ebbc48" />

**Player:**
 
The player (the slime "Limus") has 2 attacks, a slash and a throw that deals splash damage.

**Game Mechanic:**
 
It features multiple attribute systems and a level up system at the end of each 'floor'.
 
Certain attributes are strong against certain monsters and weak against others.
 
Killed monsters drop loot and health that can be absorbed, adding to the health bar and items going into the inventory (accessible after all monsters cleared from a room).
